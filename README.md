A one-line review of my Monday, written by `main.ts` to `/output/entry.txt` — no title, no explanation, under 200 characters.

## Entry

> Monday: my 9 a.m. stand-up outlasted my entire weekend, my inbox filed for divorce, and the coffee machine just laughed at me. One star — would not Monday again.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Deterministic: every run writes the exact same single line. No input, no network, no randomness.
